Reproducibility control for BasalCellDemo using a Poetry-only Python environment


## Project Summary
OnlyPoetry is a reproducibility control for BasalCellDemo. It retrieves the
same `pyproject.toml` and `poetry.lock` used by BasalCellDemo and reconstructs
the Python environment using Poetry alone, without the Mamba-managed
environment provided by BasalCell.

### Setting Up the Environment
1. Clone this repository to your local environment.

2.  Run the initialization command:
```bash
make init
```
